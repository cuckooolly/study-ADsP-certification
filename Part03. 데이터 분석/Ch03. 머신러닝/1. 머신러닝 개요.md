# 머신러닝 개요
## 1. 알고리즘 분류
### 1. 지도학습과 비지도학습
- 지도학습: 레이블이 있는 데이터를 사용하여 모델을 학습시키는 방법
- 비지도학습: 레이블이 없는 데이터를 사용하여 패턴이나 구조를 찾는 방법

### 2. 회귀(Regression)와 분류(Classification)
- 회귀: 연속적인 값을 예측하는 문제 (예: 주택 가격 예측)
- 분류: 이산적인 값을 예측하는 문제 (예: 이메일 스팸 분류)

## 2. 평가 지표
### 1. 평가 지표의 활용
- 모델의 성능을 객관적으로 평가하고 비교하기 위해 사용
- 지도학습에서는 주로 회귀와 분류 문제에 따라 다른 평가 지표를 사용하고, 비지도학습은 평가지표를 보조적으로 사용한다.
- 상황에 따라 적절한 평가 지표를 선택하며, 여러 지표를 함께 고려하는 것이 중요하다.

### 2. 회귀 평가 지표
1. MAE (평균 절대 오차)
    - 실제 값과 예측 값의 절대 오차의 평균
    - 공식: $MAE = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$
    - 해석: 값이 작을수록 예측이 정확함
2. MAPE (평균 절대 백분율 오차)
    - 실제 값과 예측 값의 절대 오차를 실제 값으로 나눈 후 평균
    - 공식: $MAPE = \frac{100\%}{n} \sum_{i=1}^{n} \left| \frac{y_i - \hat{y}_i}{y_i} \right|$
    - 해석: 값이 작을수록 예측이 정확함
3. MSE (평균 제곱 오차)
    - 실제 값과 예측 값의 제곱 오차의 평균
    - 공식: $MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$
    - 해석: 값이 작을수록 예측이 정확함
4. RMSE (평균 제곱근 오차)
    - MSE의 제곱근
    - 공식: $RMSE = \sqrt{MSE}$
    - 해석: 값이 작을수록 예측이 정확함
5. R² (결정 계수)
    - 모델이 실제 값을 얼마나 잘 설명하는지 나타내는 지표
    - 공식: $R^2 = 1 - \frac{\sum_{i=1}^{n} (y_i - \hat{y}_i)^2}{\sum_{i=1}^{n} (y_i - \bar{y})^2}$
    - 해석: 1에 가까울수록 모델이 데이터를 잘 설명함
### 3. 분류 평가 지표
- 분류 모형은 주어진 데이터가 특정한 범주에 속할 확률을 계산, 가장 높은 확률을 갖는 범주로 관측치를 분류
- 혼동 행렬(Confusion Matrix)을 통해 모델의 성능을 평가
1. 정확도(Accuracy)
    - 전체 예측 중에서 올바르게 예측한 비율
    - 공식: $Accuracy = \frac{TP + TN}{TP + TN + FP + FN}$
    - 해석: 값이 클수록 모델의 성능이 좋음
2. 오분류율(Error Rate)
    - 전체 예측 중에서 잘못 예측한 비율
    - 공식: $Error\ Rate = \frac{FP + FN}{TP + TN + FP + FN}$
    - 해석: 값이 작을수록 모델의 성능이 좋음
3. 민감도(Sensitivity, 재현율, Recall)
    - 실제 양성 중에서 올바르게 예측한 비율
    - 공식: $Sensitivity = \frac{TP}{TP + FN}$
    - 해석: 값이 클수록 모델의 성능이 좋음
4. 정밀도(Precision)
    - 양성으로 예측한 것 중에서 실제로 양성인 비율
    - 공식: $Precision = \frac{TP}{TP + FP}$
    - 해석: 값이 클수록 모델의 성능이 좋음
5. F1 스코어(F1 Score)
    - 정밀도와 민감도의 조화 평균
    - 공식: $F1\ Score = 2 \times \frac{Precision \times Sensitivity}{Precision + Sensitivity}$
    - 해석: 값이 클수록 모델의 성능이 좋음
6. FPR (False Positive Rate)
    - 실제 음성 중에서 잘못 양성으로 예측한 비율
    - 공식: $FPR = \frac{FP}{FP + TN}$
    - 해석: 값이 작을수록 모델의 성능이 좋음
7. ROC 곡선 (Receiver Operating Characteristic Curve)
    - 다양한 임계값에서의 민감도와 FPR의 관계를 나타내는 곡선
    - 해석: 곡선이 왼쪽 위에 가까울수록 모델의 성능이 좋음
8. AUC-ROC (Area Under the Curve - Receiver Operating Characteristic)
    - 다양한 임계값에서의 민감도와 특이도의 관계를 나타내는 곡선 아래 면적
    - 해석: 1에 가까울수록 모델의 성능이 좋음
### 4. 비지도학습 평가 지표
- 비지도학습에서는 명확한 정답이 없기 때문에 평가 지표가 제한적
- 주로 군집화(Clustering)와 차원 축소(Dimensionality Reduction)에서 사용
1. 실루엣 점수(Silhouette Score)
    - 군집화의 품질을 평가하는 지표
    - 공식: $s(i) = \frac{b(i) - a(i)}{max(a(i), b(i))}$
    - 해석: 값이 1에 가까울수록 군집화가 잘 되었음을 의미
2. 엘보우 방법(Elbow Method)
    - 군집 수를 결정하는 데 사용되는 방법
    - 해석: 군집 수에 따른 SSE(Sum of Squared Errors)를 그래프로 나타내어, SSE 감소가 급격히 완화되는 지점을 찾음
3. 카이제곱 검정(Chi-Squared Test)
    - 변수 간의 독립성을 평가하는 통계적 방법
    - 해석: p-값이 작을수록 변수 간에 유의미한 관계가 있음을 의미
4. 군집 간 거리 및 군집 내 거리
    - 군집화의 품질을 평가하는 지표
    - 해석: 군집 간 거리는 클수록, 군집 내 거리는 작을수록 군집화가 잘 되었음을 의미

## 3. 교차 검증
### 1. 교차 검증 활용
- 모델의 일반화 성능을 평가하기 위해 사용
- 데이터를 여러 개의 폴드(fold)로 나누어, 각 폴드를 검증 세트로 사용하고 나머지 폴드를 훈련 세트로 사용
- K-겹 교차 검증(K-Fold Cross-Validation)이 가장 일반적으로 사용됨
- 교차 검증을 통해 모델의 과적합(overfitting)을 방지하고, 하이퍼파라미터 튜닝에 활용할 수 있음
- 교차 검증 결과를 바탕으로 모델의 성능을 객관적으로 평가하고 비교할 수 있음
- 교차 검증은 특히 데이터가 적을 때 유용하며, 모델의 안정성을 높이는 데 기여함

### 2. 홀드아웃 검증
- 데이터를 훈련 세트와 테스트 세트로 나누어 모델을 평가하는 방법
- 일반적으로 70-80%를 훈련 세트로, 20-30%를 테스트 세트로 사용
- 간단하고 빠르게 모델을 평가할 수 있지만, 데이터 분할에 따라 결과가 달라질 수 있음
- 데이터가 충분히 크지 않은 경우, 홀드아웃 검증은 모델의 일반화 성능을 정확하게 평가하지 못할 수 있음
- 교차 검증에 비해 과적합을 방지하는 데 덜 효과적일 수 있음

### 3. K-Fold 교차 검증
- 데이터를 K개의 폴드로 나누어, 각 폴드를 한 번씩 검증 세트로 사용하고 나머지 폴드를 훈련 세트로 사용하는 방법
- 일반적으로 K=5 또는 K=10이 많이 사용됨
- 모든 데이터가 훈련과 검증에 사용되므로, 모델의 일반화 성능을 더 정확하게 평가할 수 있음
- 데이터가 적을 때 특히 유용하며, 모델의 안정성을 높이는 데 기여함
- 교차 검증 결과를 바탕으로 하이퍼파라미터 튜닝에 활용할 수 있음

### 4. 층화 K-Fold 교차 검증
- 분류 문제에서 각 폴드가 전체 데이터의 클래스 비율을 유지하도록 나누는 방법
- 클래스 불균형이 있는 데이터셋에서 모델의 성능을 더 정확하게 평가할 수 있음
- 일반적인 K-Fold 교차 검증과 동일한 절차를 따르지만, 각 폴드가 클래스 비율을 반영하도록 함
- 모델의 일반화 성능을 더 신뢰성 있게 평가할 수 있음
