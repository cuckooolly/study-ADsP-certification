# 지도학습
## 1. 선형회귀
### 1. 단순 선형회귀와 다중 선형회귀
1. 단순 선형회귀
    - 하나의 설명 변수 x로 y를 설명하는 모형
    - 수식: $y = \beta_0 + \beta_1 x + \epsilon$
    - 2차원 공간의 직선 방정식의 형태로 x가 1 증가할 때마다 y사 이에 $\beta_1$만큼 증가
    - 오차항($\epsilon$)은 설명 변수로 설명하지 못하는 부분을 나타냄
2. 다중 선형회귀
    - 여러 개의 설명 변수로 관심변수 y를 설명하는 모형, p개의 설명 변수를 가질 수 있음
    - 수식: $y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_p x_p + \epsilon$
    - 다차원 공간에서 평면 또는 초평면의 형태로 각 설명 변수가 1 증가할 때마다 y가 해당 변수의 회귀계수만큼 증가
    - 오차항($\epsilon$)은 설명 변수로 설명하지 못하는 부분을 나타냄
### 2. 선형회귀의 주요 가정
1. 선형성
    - 설명 변수와 관심 변수 간의 관계가 선형이어야 함
    - 다중 선형회귀에서는 각 설명 변수와 관심 변수 간의 관계가 선형이어야 함
2. 독립성
    - 관측치들이 서로 독립적이어야 함
    - 시계열 데이터에서는 자기상관이 존재할 수 있으므로 주의 필요
3. 정규성
    - 오차항이 정규분포를 따라야 함
    - 잔차 분석을 통해 확인 가능
4. 등분산성
    - 오차항의 분산이 일정해야 함
    - 잔차 플롯을 통해 확인 가능
### 3. 비선형 관계를 반영한 회귀 모형
1. 다항 회귀
    - 설명 변수의 d차 다항식을 활용해 d차 곡선 및 곡면의 형태로 관심변수를 설명
    - 설명 변수의 다항식을 사용하여 비선형 관계를 모델링
    - 2개 이상의 설명 변수를 활용할 수 있으며, 두 설명 변수를 곱한 변수도 포함
    - 다중공선성 문제가 발생할 가능성이 높고, d가 커질수록 과적합 위험이 증가
    - 예: $y = \beta_0 + \beta_1 x + \beta_2 x^2 + ... + \beta_k x^k + \epsilon$
2. 비선형 회귀
    - 설명 변수의 선형 결합에 지수, 로그와 같은 비선형 변환 함수를 적용하여 관심 변수를 설명
    - 비선형 함수를 사용하여 설명 변수와 관심 변수 간의 관계를 모델링
    - 일반적으로 선형과 비선형의 구분은 모형식에서 각 설명 변수의 항이 "+"로 연결되어 분리가 가능한지를 기준으로 판단
    - 예: $y = \beta_0 + \beta_1 e^{\beta_2 x} + \epsilon$
### 4. 모형 적합 방법
1. 최적 회귀 방정식 계산
    - 실제 값과 모형식을 활용한 예측 값의 차이(오차)를 최소화하는 회귀 계수를 계산하고, 데이터에 적합한 최적 회귀 방정식을 계산
    - 최소제곱법은 오차의 제곱합을 최소화하는 방향으로 회귀계수를 계산하며, 이렇게 계산된 회귀계수를 최소제곱추정량이라 한다.
    - 예시) 단순 선형회귀의 오차 제곱합
      - $S(\beta_0, \beta_1) = \sum_{i=1}^{n} (y_i - (\beta_0 + \beta_1 x_i))^2$
2. 변수 선택 및 특성 선택
    - 계산된 회귀 계수($\beta_1$)가 0에 충분히 가까운 경우, $\beta_jX_j$도 0에 가까운 값으로 계산되며, $x_j$는 관심 변수 $y$에 거의 영향을 미치지 않음
    - 아래 가설로 회귀 계수 검정을 수행하여 유의하지 않은 설명 변수를 제거
      - 귀무가설($H_0$): $\beta_j = 0$ (설명 변수 $X_j$가 관심 변수 $y$에 영향을 미치지 않음) // 변수 $X_j$는 필요 없다.
      - 대립가설($H_a$): $\beta_j \neq 0$ (설명 변수 $X_j$가 관심 변수 $y$에 영향을 미침) // 변수 $X_j$는 필요 하다.
3. 변수 선택 방법
    - 회귀 모형에서 각 변수의 회귀 계수에 대한 검정과 모형의 성능 지표를 활용하여 모형에 필요한 변수를 순차적으로 선택 혹은 제거할 수 있고, 아래와 같은 방법을 활용한다.
      - 전진 선택법(Forward Selection): 빈 모형에서 시작하여 유의한 변수를 하나씩 추가
      - 후진 제거법(Backward Elimination): 전체 변수를 포함한 모형에서 시작하여 유의하지 않은 변수를 하나씩 제거
      - 단계적 선택법(Stepwise Selection): 전진 선택법과 후진 제거법을 결합하여 변수를 추가하거나 제거
4. 모형식을 활용한 예측
    - 최적 회귀 방정식을 활용하여 새로운 관측치에 대한 관심 변수 값을 예측
    - 예측 값 계산: $\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_p x_p$
    - 모형 평가 지표 등을 계산할 때, 실제 값($y_i$)과 예측 값($\hat{y_i}$)의 차이($y_i-\hat{y_i}$)를 활용하여 모델의 성능을 평가
5. 회귀 모형 평가
    - 수치형 관심변수를 활용하는 선형회귀는 모형평가, 변수 선택과정에서 RMSE, MAE, R² 등의 평가 지표를 활용
    - $R^2$은 변수의 유의성 여부와 상관없이 더 많은 변수를 활용한 모형이 더 높은 값을 갖고 좋은 모형으로 평가될 수 있으므로, 모형의 성능과 효율을 함께 고려해 변수의 개수를 고려한 평가지표를 활용
    - 예: 조정된 결정계수(Adjusted R²)
      - 공식: $Adjusted\ R^2 = 1 - (1 - R^2) \frac{n - 1}{n - p - 1}$
      - n: 관측치 수, p: 설명 변수 수
      - 해석: 값이 클수록 모델이 데이터를 잘 설명하며, 변수의 개수를 고려하여 평가
    - 예: AIC (Akaike Information Criterion)
      - 공식: $AIC = 2p - 2\log(\frac {\sum^n_{n=1}(y_i-\hat{y_i})} {n}) + 2k$
      - p: 설명 변수 수, L: 최대 우도 함수 값
      - 해석: 값이 작을수록 모델의 성능이 좋음
    - 예: BIC (Bayesian Information Criterion)
      - 공식: $BIC = p \log(\frac {\sum^n_{n=1}(y_i-\hat{y_i})} {n}) + klog(n)$
      - p: 설명 변수 수, n: 관측치 수, L: 최대 우도 함수 값
      - 해석: 값이 작을수록 모델의 성능이 좋음
    - 예: Mallow's $C_p$
      - 공식: $C_p = \frac{\sum_{i=1}^{n} (y_i - \hat{y_i})^2}{\hat{\sigma}^2} - n + 2(k+1)$
      - $\hat{\sigma}^2$: 전체 모형의 잔차 제곱평균, p: 설명 변수 수, n: 관측치 수
      - 해석: 값이 작을수록 모델의 성능이 좋음
### 5. 정규화 선형회귀

- 선형회귀 모형에 정규화(규제) 기법을 추가하여 과적합을 방지하고, 모델의 일반화 성능을 향상시키는 방법
1. 릿지 회귀(Ridge Regression)
    - 회귀 계수의 크기를 제한하여 과적합을 방지하는 정규화 기법
    - 비용 함수에 L2 정규화 항을 추가하여 회귀 계수를 제어
    - 비용 함수: $J(\beta) = \sum_{i=1}^{n} (y_i - \hat{y_i})^2 + \lambda \sum_{j=1}^{p} \beta_j^2$
    - $\lambda$는 정규화 강도를 조절하는 하이퍼파라미터로, 값이 클수록 회귀 계수가 더 작아짐
2. 라쏘 회귀
    - 회귀 계수의 절대값 합을 제한하여 과적합을 방지하는 정규화 기법
    - 비용 함수에 L1 정규화 항을 추가하여 회귀 계수를 제어
    - 비용 함수: $J(\beta) = \sum_{i=1}^{n} (y_i - \hat{y_i})^2 + \lambda \sum_{j=1}^{p} |\beta_j|$
    - $\lambda$는 정규화 강도를 조절하는 하이퍼파라미터로, 값이 클수록 일부 회귀 계수가 0이 되어 변수 선택 효과도 있음
3. 엘라스틱 넷 회귀(Elastic Net Regression)
    - 릿지 회귀와 라쏘 회귀의 장점을 결합한 정규화 기법
    - 비용 함수에 L1과 L2 정규화 항을 모두 추가하여 회귀 계수를 제어
    - 비용 함수: $J(\beta) = \sum_{i=1}^{n} (y_i - \hat{y_i})^2 + \lambda_1 \sum_{j=1}^{p} |\beta_j| + \lambda_2 \sum_{j=1}^{p} \beta_j^2$
    - $\lambda_1$과 $\lambda_2$는 각각 L1과 L2 정규화 강도를 조절하는 하이퍼파라미터

## 2. 로지스틱 회귀
### 1. 로지스틱 회귀 개요
- 이진 분류 문제를 해결하기 위한 지도학습 알고리즘
- 관심 변수 y가 특정 범주에 속할 확률을 계산하고 예측에 활용
- 시그모이드 함수 혹은 로지스틱 함수를 활용하여 확률 값을 0과 1 사이로 변환
  - 시그모이드 함수: $S(z) = \frac{1}{1 + e^{-z}}$
  - 로지스틱 회귀 모형식: $P(y=1|X) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_p x_p)}}$
### 2. 로지스틱 회귀 개념 이해
1. 오즈(Odds)
    - 오즈: 사건이 발생할 확률과 발생하지 않을 확률의 비율
      - 공식: $Odds = \frac{P(y=1|X)}{1 - P(y=1|X)}$
2. 로그 오즈(Log-Odds)
    - 로그 오즈: 오즈의 자연로그 변환
      - 공식: $Log-Odds = \log\left(\frac{P(y=1|X)}{1 - P(y=1|X)}\right)$
### 3. 모형 적합 방법
1. Log loss의 정의
    - 로지스틱 회귀에서 모형 적합을 위해 사용되는 손실 함수
    - 관측치의 실제 값과 예측 확률 간의 차이를 측정
    - 공식: $Log\ Loss = -\frac{1}{n} \sum_{i=1}^{n} \left[ y_i \log(\hat{y_i}) + (1 - y_i) \log(1 - \hat{y_i}) \right]$
2. 회귀 계수 추정
    - 선형회귀 모형과 마찬가지로 모든 관측치 $l_i$의 합 $l$을 최소화하는 회귀 계수 $\beta_i$를 추정
    - 실제 회귀 계수의 계산 과정에서는 경사하강법을 활용해 점진적으로 더 나은 값을 찾아가는 수치해석 등의 방법을 활용한다.

## 3. 나이브 베이즈 분류
### 1. 개념
- 베이즈 정리를 기반으로 한 확률적 분류 알고리즘
- 각 특징이 독립적이라는 가정 하에 클래스에 속할 확률을 계산
- 베이즈 정리: $P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$
- 나이브 베이즈 분류 모형식: $P(C_k|X) = \frac{P(X|C_k) \cdot P(C_k)}{P(X)}$
### 2. 확률 계산 및 분류
- 관심변수 y가 k개의 클래스 $C_1, C_2, ..., C_k$를 가질 때, 새로운 관측치 X에 대해 각 클래스에 속할 확률을 계산
- 별도의 추정 과정 없이 학습 데이터에서 각 클래스의 사전 확률 $P(C_k)$와 특징의 조건부 확률 $P(X|C_k)$를 계산하여 사용
- 새로운 관측치 X에 대해 각 클래스에 속할 확률을 계산하고, 가장 높은 확률을 갖는 클래스로 분류
- 분류 결정: $\hat{C} = \arg\max_{C_k} P(C_k|X)$

## 4. 서포트 백터 머신
- 회귀와 분류에 모두 활용 가능하나, 일반적으로 이진 분류에 활용하여 관심 변수 y가 두 개의 클래스(예: 1과 -1)로 구분되는 문제를 해결
- 범주 또는 클래스가 가장 큰 마진을 두고 나뉠 수 있도록 결정 경계(Decision Boundary)를 찾는 것을 목표
- 결정 경계는 서포트 벡터(Support Vectors)라 불리는 가장 가까운 데이터 포인트에 의해 결정
- 선형 SVM과 비선형 SVM으로 구분
1. 선형 SVM
    - 데이터가 선형적으로 구분 가능한 경우, 최적의 결정 경계를 찾기 위해 선형 초평면을 사용
    - 결정 경계 수식: $w \cdot x + b = 0$
    - 마진 최대화: $\text{maximize} \frac{2}{||w||}$
2. 비선형 SVM
    - 데이터가 선형적으로 구분되지 않는 경우, 커널 트릭(Kernel Trick)을 활용하여 고차원 공간으로 매핑
    - 커널 함수 예시:
      - 다항 커널: $K(x_i, x_j) = (x_i \cdot x_j + c)^d$
      - RBF 커널: $K(x_i, x_j) = \exp(-\gamma ||x_i - x_j||^2)$
- SVM은 강력한 분류 성능과 일반화 능력을 갖추고 있어 다양한 분야에서 널리 사용

## 5. K-NN (K-최근접 이웃)
- 회귀와 분류에 모두 활용 가능한 모형으로, 거리를 기준으로 예측하며, 모형식이나 분포 가정을 활용하지 않아 별도의 학습이 필요 없는 비모수적 알고리즘이다.
- 새로운 관측치에 대해 기존 데이터에서 가장 가까운 K개 관측치를 선택하고 K개 y값의 평균(회귀)나 다수결(분류)로 예측값을 계산한다.
- 직관적이고 구현이 간단하지만, 거리 계산 과정에 시간 소모가 클 수 있고 k값의 설정이나 거리 계산 방법에 따라 예측 결과가 크게 차이날 수 있으며, 설명 변수가 범주형일 경우 거리 계산이 어려울 수 있다.

## 6. 의사결정나무
### 1. 개요
- 회귀와 분류에 모두 활용 가능하고, 회귀 나무와 분류 나무로 구분해서 부르기도 한다.
- 노드라 부르는 관측치의 묶음을 쪼개 더 작은 하위 노드로 분할하며, 분할된 노드간 관계가 나무 구조로 표현된다.
- 가장 상위 노드를 루트 노드(Root Node), 가장 하위 노드를 잎 노드(Leaf Node)라 부른다.
- 가지치기(Pruning) 기법을 활용해, 불필요한 분할을 제거하고 모형을 단순화할 수 있다 -> 과적합 방지

### 2. 회귀 나무
- 수치형 관심변수 y를 설명하는 모형으로 분산을 최소화하는 설명 변수와 기준값 조건을 탐색하고 노드를 분할한다.

1. 분산을 활용한 최적 분할
    - 특정 노드에 속한 관측치의 y값이 얼마나 다른지를 노드 평균 값 기준 오차 제곱합으로 계산
    - S는 특정 노드 N에 속한 관측치의 인덱스 집합이며, $\bar{y}_N$는 노드 N에 속한 관측치 y값의 평균과 같다.
      - $SS_N = \sum_{i \in S_N} (y_i - \bar{y}_N)^2$
    - 해당 노드 N이 특정 조건과 일치하는 하위노드 T와 조건이 일치하지 않는 F로 분할된다고 할 때, 두 하위 노드의 오차 제곱합을 각각 계산할 수 있다.
      - $SS_T = \sum_{i \in S_T} (y_i - \bar{y}_T)^2$  
      - $SS_F = \sum_{i \in S_F} (y_i - \bar{y}_F)^2$
    - 분산 감소량은 다음과 같이 계산된다: 상위 노드 평균 기준 제곱합에 비해, 각 하위 노드 평균 기준 제곱합이 얼마나 작은지를 의미함.
      - $\Delta SS = SS_N - (SS_T + SS_F)$
    - 모든 설명 변수와 각 설명 변수의 값을 활용한 조건 중에서 위의 분산 감소량이 가장 큰 조건을 최적 분할 조건으로 선택
      - $SS_N$과 $SS_T + SS_F$의 차이가 클수록, 즉 $\Delta SS$가 클수록 분할 후 하위 노드의 관측치 y값이 더 유사해짐을 의미
      - 따라서, $\Delta SS$가 최대가 되는 조건을 선택하여 노드를 분할
2. 가지치기
- 이론적으로 관측치 개수 만큼의 노드를 가질 수 있는 나무 모형에서 성능과 모형의 복잡도 사이의 균형을 이루기 위해 가지치기 기법을 활용
  - 터미널 노드는 뿌리 노드에에서 시작한 후 여러 번의 분할을 거쳐 만들어진 종착점으로 더 이상 분할되지 않는 노드를 의미
- 비용복잡도 함수를 설정하고 비용복잡도 모수 $\alpha$를 조절하여 가지치기 수행
  - 비용복잡도 함수: $C_\alpha(T) = \sum_{m=1}^{|T|} \sum_{i \in S_m} (y_i - \bar{y}_m)^2 + \alpha |T|$
  - $|T|$: 터미널 노드의 개수, $S_m$: 터미널 노드 m에 속한 관측치의 인덱스 집합, $\bar{y}_m$: 터미널 노드 m에 속한 관측치 y값의 평균
  - $\alpha$ 값이 클수록 가지치기가 더 많이 이루어짐
### 3. 분류 나무
- 범주형 관심변수 y를 설명하는 모형으로 지니 불순도(Gini Impurity)나 엔트로피(Entropy)를 활용해 노드를 분할한다.
- 불순도를 최소화하고 특정 범주의 비율을 1에 가깝게하고 나머지 범주의 비율을 0에 가깝게 하는 설명 변수 조건을 탐색하고 노드를 분할한다.

1. 지니 불순도 혹은 지니 계수
   - 모든 범주가 동일한 비율을 갖고 있을 때, $\frac{k-1}{k}$로 최대가 되고, 특정 범주가 1의 비율을 가질 때 최소값이 0이 되는 특성을 갖는다.
     - $Gini = 1 - \sum_{j=1}^{k} p_j^2$
     - k: 범주의 개수, $p_j$: 범주 j의 비율
2. 엔트로피
   - 정보 이론에 기반한 불확실성 지표로, 0부터 $log_2(k)$까지의 값을 가질 수 있다.
   - 특정 범주가 1의 비율을 가질 때 최소값이 0이 되고, 모든 범주가 동일한 비율을 갖고 있을 때 최대가 된다.
     - $Entropy = - \sum_{j=1}^{k} p_j \log_2(p_j)$
     - k: 범주의 개수, $p_j$: 범주 j의 비율

## 7. 앙상블 기법
### 1. 개요
- 여러 개의 모형을 결합해 개별 모형이 가진 단점을 상호 보완하고 성능을 향상 시키기 위해 활용한다.
- 예측과정에서 각 모형의 예측값을 종합하여 최종 예측값을 계산하므로, 모형의 정확도와 안정성을 높이는 데 효과적
- 복수 모형을 활용하기 위해, 더 많은 연산 자원이 필요하고 앙상블 모형을 설명하기 위해 개별 모형을 모두 설명해야 하는 어려움이 따른다.
- 앙상블 기법은 배깅(Bagging)과 부스팅(Boosting), 스태킹(Stacking)으로 구분
### 2. 배깅 (Bagging)
- 재표본 추출을 통해 데이터를 여러 번 재구성하고 추정이나 모형 적합을 반복하면서 표준 오차 계산, 신뢰 구간 추정 등에 활용
- 배깅은 부트스크랩 방법으로 모형 적합을 반복하고, 예측값 등을 계산할 때 복수 모형의 결과를 요약, 집계하여 평균이나 다수결 등의 방법으로 최종 예측값을 계산하는 앙상블 기법
- 모형 적합 과정에서 추출된 표본에 따라 모형 적합 결과와 예측값이 달라지며, 다양한 관측치 조합으로 학습된 모형을 종합함으로써 모형의 변동성을 줄이고 과적합을 방지하며 성능향상을 기대할 수 있다.
#### 랜덤 포레스트
- 의사결정나무에 배깅을 적용한 앙상블 모형이다.
- 랜덤으로 선택한 관측치와 변수를 활용하여 나무 모형을 적합하고, 반복을 통해 복수 나무로 예측 등에 활용한다.
  - 관측치 랜덤: 배깅을 활용한 학습용 데이터 선택 및 반복
  - 변수 랜덤: 매 노드 분할 과정에서 모든 변수를 활용하는 나무 모형과 달리, 무작위로 선택한 일부 변수만 활용
- 회귀 문제에서는 복수 나무 모형 예측값의 평균을 최종 예측값으로 활용하고 분류 문제에서는 예측 확률의 평균이나 예측 범주 다수결 등을 최종 예측 값으로 활용할 수 있다.
- 랜덤 포레스트는 나무 모형 개수, 관측치 표본 추출 비율, 분할 후보 변수 개수 혹은 비율 등의 하이퍼파라미터를 활용하며, 교차 검증 등을 통해 최적 조합을 탐색한다.

### 3. 부스팅 (Boosting)
- 부스팅은 배깅과 달리 앙상블에 활용되는 모형이 서로 독립적이지 않고, 이전 모형의 오차나 오류를 보완하기 위한 모형을 순차적으로 학습하고 성능을 향상 시키는 앙상블 기법이다.
- 대표적인 알고리즘에는 AdaBosst, 그래디언트 부스팅(Gradient Boosting), XGBoost, LightGBM, CatBoost 등이 있다.
- 부스팅 모형은 비교적 간단한 모형의 조합으로 구성되며, 알고리즘에 따라 세부적인 앙상블 변화에 차이가 있다.
- AdaBoost는 이전 모형에서 잘못 예측된 관측치에 더 높은 가중치를 부여하여 다음 모형이 이를 보완하도록 학습한다.
- 그래디언트 부스팅은 이전 모형의 잔차(오차)를 예측하는 새로운 모형을 순차적으로 추가하여 전체 모형의 성능을 향상 시킨다.
- XGBoost, LightGBM, CatBoost는 그래디언트 부스팅의 효율성과 성능을 개선한 알고리즘으로, 대규모 데이터셋과 복잡한 문제에 효과적이다.
- 나무 모형 개수, 각 노드의 분할이나 개별 모형에서 학습된 정보를 축소 반영하는 비율인 학습률과 같은 하이퍼파라미터를 활용하며, 과적합 등을 방지하기 위해 배깅 기법을 접목할 수도 있다.

### 4. 스태킹 (Stacking)
- 독립적이고 서로 다른 모형의 예측 결과를 바탕으로 최종 예측값을 생성하는 규칙이나 모형을 개발하고 활용하는 앙상블 기법
- 개별 모형의 제약은 없으며, 일반적으로 서로 다른 종류나 서로 다른 하이퍼파리미터로 적합된 모형을 앙상블하여 다양한 예측 패턴을 반영하고 성능을 높이는데 초점을 둔다.
- 단순한 방법으로는 복수 모형의 예측값의 평균이나 예측 범주에 대한 다수결 등을 활용할 수 있고, 각 모형의 예측값을 설명변수로 하는 별도의 모형(메타모형)을 적합하고 예측값을 계산할 수도 있다.

## 8. 인공신경망 모형
### 1. 개요
- 뉴런이 시냅스를 통해 신호를 전달하는 생물의 신경망을 모방하여 생성한 알고리즘
- 인공신경망은 입력층, 은닉층, 출력층으로 구성되며, 각 층은 여러 개의 노드(뉴런)로 이루어져 있다.
  - 입력층은 데이터를 받아들이고, 은닉층은 데이터의 패턴을 학습하며, 출력층은 예측값을 구성한다.
- 각 층은 복수의 뉴련(노드)로 구성되며, 뉴런은 이전 층의 $p$개 입력값 $x_j$를 가중치($w$)와 편향($b$), 활성화 함수($f$)를 활용해 하나의 출력값 $z$로 변환한다.
  - $z = f(\sum_{j=1}^{p} w_j x_j + b) = f(w_1x_1+...+w_px_p+b)$
- 입력 데이터의 선형 결합에 활성화 함수를 적용하여, 비선형성을 추가하고 신경망이 복잡한 패턴을 학습할 수 있도록 한다.
- 기존 알고리즘에 비해 이미지와 텍스트 등 비정형 데이터의 복잡한 구조나 비선형 패턴을 잘 설명하여 이미지와 텍스트의 분류, 패턴 인식 등에 주로 활용한다.
- 모형의 구조 설계가 까다롭고 시행착오를 통해 최적의 구조를 탐색해야 하며, 상대적으로 복잡한 구조로 입력값의 처리, 초기 가중치 값 설정, 모형 구조에 민감하다.
- 모형이 복잡할수록 성능 개선에 도움이 될 수 있으나, 노드의 개수에 비례해 더 많은 연산과 학습 시간이 소요되고 결과 해석이 어렵다.

### 2. 층 구성
- 입력층(Input Layer): 원본 데이터를 받아들이는 층으로, 각 노드는 하나의 특징(설명 변수)을 나타낸다.
- 은닉층(Hidden Layer): 입력층과 출력층 사이에 위치하며, 데이터의 패턴을 학습하는 층이다. 하나 이상의 은닉층을 가질 수 있으며, 각 층의 노드 수와 활성화 함수는 모형의 성능에 영향을 미친다.
- 출력층(Output Layer): 최종 예측값을 생성하는 층으로, 회귀 문제에서는 하나의 노드가 연속형 값을 출력하고, 분류 문제에서는 클래스 개수에 따라 여러 개의 노드를 가질 수 있다.

### 3. 활성화 함수
- 층의 위치와 역할에 따라 각 노드에서 적절한 활성 함수를 설정하고 활용한다.
1. 계산 함수와 부호 함수
2. 시그모이드 함수(Sigmoid Function)
    - 출력값을 0과 1 사이로 변환하는 함수로, 이진 분류 문제의 출력층에서 주로 사용
    - 공식: $S(z) = \frac{1}{1 + e^{-z}}$
3. 렐루 함수(ReLU, Rectified Linear Unit)
    - 음수 입력에 대해 0을 출력하고, 양수 입력에 대해 입력 값을 그대로 출력하는 함수로, 은닉층에서 주로 사용
    - 공식: $ReLU(z) = \max(0, z)$
4. 소프트맥스 함수(Softmax Function)
    - 다중 클래스 분류 문제의 출력층에서 사용되며, 각 클래스에 속할 확률을 계산
    - 공식: $Softmax(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{k} e^{z_j}}$
    - $z_i$: 클래스 i에 대한 입력값, k: 클래스의 총 개수

### 4. 층 구성에 따른 모형 구분
1. 퍼셉트론
    - 단일 층으로 구성된 신경망 모형으로, 선형 분류 문제에 활용
    - 은닉층 없이 입력층과 출력층이 직접 연결되는 기본적인 형태의 단층 신경망 구조
2. 다층 퍼셉트론(MLP, Multi-Layer Perceptron)
    - 하나 이상의 은닉층을 가진 신경망 모형으로, 복잡한 패턴을 학습할 수 있다.

### 5. 모형 학습 과정
1. 순전파(Forward Propagation)
    - 입력 데이터를 신경망을 통해 전달하여 각 층의 노드에서 출력값을 계산
    - 각 노드에서 가중치와 편향, 활성화 함수를 활용해 출력값을 생성하고, 최종 출력층에서 예측값을 도출
2. 손실 함수(Loss Function)
    - 예측값과 실제 값 간의 차이를 측정하는 함수로, 회귀 문제에서는 평균 제곱 오차(MSE), 분류 문제에서는 교차 엔트로피 손실(Cross-Entropy Loss) 등을 사용
3. 역전파(Backpropagation)
    - 손실 함수를 최소화하기 위해 가중치와 편향을 조정하는 과정
    - 손실 함수의 기울기를 계산하고, 이를 활용해 가중치와 편향을 업데이트
4. 가중치 업데이트
    - 최적화 함수를 활용하여 가중치와 편향 등 모형의 파라미터를 업데이트한다.
    - 대표적인 최적화 함수로는 확률적 경사 하강법(SGD, Stochastic Gradient Descent), Adam, RMSprop 등이 있다.
    - 학습률(Learning Rate)은 가중치 업데이트의 크기를 조절하는 하이퍼파라미터로, 적절한 값을 설정해야 안정적인 학습이 가능하다.
    - 가중치 업데이트 공식: $w = w - \eta \cdot \nabla L(w)$
      - $w$: 가중치, $\eta$: 학습률, $\nabla L(w)$: 손실 함수의 기울기
5. 반복과 수렴
    - 업데이트된 가중치를 활용해 순전파, 손실 계산, 역전파가 이뤄지고 가중치가 다시 업데이트되며 이 과정을 모형이 수렴할 때까지 선택
    - 학습률 설정과 별개로 모형의 과적합이 발생할 수 있으므로, 별도의 평가 데이터를 활용하여 손실함수 및 모형 평가 지표를 계산하고 적절한 지점에서 모형 학습을 중단할 수 있다.

## 9. 시계열 데이터 분석
### 1. 개요
- 시계열 데이터는 관측치들이 서로 독립적이지 않고 한 대상에 대해 시점에 따라 연속적인 값을 특수한 형태로 기록한 데이터
- 시계열 데이터는 시점 $t$에 따라 변하는 값이며, $t+1$ 시점의 관측치는 밀접한 관련이 있을 가능성이 크고 시간 순서를 지켜 분석해야 한다.
- 시계열 분석에서는 시계열 데이터에 대해서 정상성을 가정하며, AR, MA, ARMA, ARIMA 모형 등이 활용된다.
### 2. 정상성
- 시계열 데이터의 통계적 특성이 시간에 따라 변하지 않는 성질
- 정상성의 주요 조건
  1. 평균 일정성: 시계열 데이터의 평균이 시간에 따라 일정해야 함
  2. 자기 공분산 일정성: 시계열 데이터의 자기 공분산이 시간에 따라 일정해야 함
  3. 공분산 일정성: 시계열 데이터의 공분산이 시간에 따라 일정해야 함
- 정상성 여부는 선 그래프와 같은 시각화나 ADF 검정, ACF나 PACF 패턴으로 판단한다.
- 비정상성 데이터를 정상성을 갖는 데이터로 변환을 시도해볼 수 있으며, 시점간 차이를 계산하는 차분이나 분산이 시간에 따르 증가하는 경우, 로그, 제곱근 변환 등을 활용한다.

### 3. 자기회귀 모형
- 시계열의 과거 값을 설명 변수로 사용해서 현재 시점의 값을 설명하는 모형으로 자기 상관성이 높은 시계열 데이터에 유리하며, 특정 시점의 값이 과거의 여러 값에 의존할 때 효과적이다.
- 자기회귀 모형은 AR(p)로 표기하며, p는 시차의 개수를 의미한다.
- AR(p) 모형식: $y_t = c + \phi_1 y_{t-1} + \phi_2 y_{t-2} + ... + \phi_p y_{t-p} + \epsilon_t$
  - $y_t$: 시점 t의 관측치, c: 상수항, $\phi_i$: 시차 i에 대한 회귀 계수, $\epsilon_t$: 백색잡음(오차항)

### 4. 이동평균 모형
- 시계열의 과거 시점의 오차항을 이용해 현재 시점의 값을 설명하는 모형으로, $MA(q)$로 표기하며, q는 시차의 개수를 의미한다.
- MA(q) 모형식: $y_t = c + \epsilon_t + \theta_1 \epsilon_{t-1} + \theta_2 \epsilon_{t-2} + ... + \theta_q \epsilon_{t-q}$
  - $y_t$: 시점 t의 관측치, c: 상수항, $\theta_i$: 시차 i에 대한 회귀 계수, $\epsilon_t$: 백색잡음(오차항)

### 5. 자기회귀 이동평균 모형
- 자기회귀 모형과 이동평균 모형을 결합한 모형으로, $ARMA(p, q)$로 표기하며, p는 자기회귀 시차의 개수, q는 이동평균 시차의 개수를 의미한다.
- ARMA(p, q) 모형식: $y_t = c + \phi_1 y_{t-1} + ... + \phi_p y_{t-p} + \epsilon_t + \theta_1 \epsilon_{t-1} + ... + \theta_q \epsilon_{t-q}$
  - $y_t$: 시점 t의 관측치, c: 상수항, $\phi_i$: 자기회귀 시차 i에 대한 회귀 계수, $\theta_i$: 이동평균 시차 i에 대한 회귀 계수, $\epsilon_t$: 백색잡음(오차항)

### 6. 자기회귀누적이동평균 모형
- 비정상성 시계열 데이터를 정상성으로 변환하기 위해 차분을 적용한 후, ARMA 모형을 적합하는 방법
- $ARIMA(p, d, q)$로 표기하며, p는 자기회귀 시차의 개수, d는 차분 횟수, q는 이동평균 시차의 개수를 의미한다.
  - ARIMA(p, d, q) 모형식: $\Delta^d y_t = c + \phi_1 \Delta^d y_{t-1} + ... + \phi_p \Delta^d y_{t-p} + \epsilon_t + \theta_1 \epsilon_{t-1} + ... + \theta_q \epsilon_{t-q}

### 7. 시계열 분해
- 시계열 데이터를 추세(Trend), 계절성(Seasonality), 잔차(Residual) 성분으로 분해하여 각 성분을 개별적으로 분석하는 방법
1. 추세 성분
    - 시계열 데이터의 장기적인 증가 또는 감소 경향을 나타내는 성분
2. 계절성 성분
    - 일정한 주기로 반복되는 패턴을 나타내는 성분
3. 잔차 성분
    - 추세와 계절성을 제거한 후 남은 불규칙한 변동 성분
4. 가법 모형과 승법 모형
    - $t$ 시점의 관측치 $y_t$가 추세 성분 $T_t$, 계절성 성분 $S_t$, 잔차 성분 $R_t$의 합으로 표현되는 가법 모형
      - 가법 모형: $y_t = T_t + S_t + R_t$
    - $t$ 시점의 관측치 $y_t$가 추세 성분 $T_t$, 계절성 성분 $S_t$, 잔차 성분 $R_t$의 곱으로 표현되는 승법 모형
      - 승법 모형: $y_t = T_t \times S_t \times R_t$
    - 일반적으로 가법 모형을 활용하며, 계절성과 추세가 비례하는 등, 변동의 크기가 증가하거나 감소하면서 변화하는 경우에는 승법 모형을 사용할 수 있다.

### 8. 이동평균
- 시계열 데이터에서 연속적인 값들의 평균을 계산하고 불규칙성 요소나 백색 잡음을 줄이는 과정을 평활이라고 한다.
- 일정 기간의 평균을 계산해 시계열의 불규칙성을 제거하고 변동성을 줄이며 전체적인 추세를 부드럽게 나타내고 전체적인 경향성과 패턴을 파악할 수 있다.
1. 단순 이동평균(SMA, Simple Moving Average)
    - 일정 기간 동안의 관측치의 산술 평균을 계산하는 방법
    - 공식: $SMA_t = \frac{1}{n} \sum_{i=0}^{n-1} y_{t-i}$
      - $SMA_t$: 시점 t의 단순 이동평균, n: 이동평균 기간, $y_{t-i}$: 시점 t-i의 관측치
2. 가중 이동평균(WMA, Weighted Moving Average)
    - 최근 관측치에 더 높은 가중치를 부여하여 평균을 계산하는 방법
    - 공식: $WMA_t = \frac{\sum_{i=0}^{n-1} w_i y_{t-i}}{\sum_{i=0}^{n-1} w_i}$
      - $WMA_t$: 시점 t의 가중 이동평균, $w_i$: 시점 t-i의 가중치, n: 이동평균 기간, $y_{t-i}$: 시점 t-i의 관측치
3. 지수 이동평균(EMA, Exponential Moving Average)
    - 최근 관측치에 지수적으로 더 높은 가중치를 부여하여 평균을 계산하는 방법
    - 공식: $EMA_t = \alpha y_t + (1 - \alpha) EMA_{t-1}$
      - $EMA_t$: 시점 t의 지수 이동평균, $\alpha$: 평활 상수(0 < α ≤ 1), $y_t$: 시점 t의 관측치, $EMA_{t-1}$: 시점 t-1의 지수 이동평균
      - 평활 상수 $\alpha$는 최근 관측치에 대한 가중치를 조절하며, 값이 클수록 최근 관측치에 더 높은 가중치를 부여한다.
      - 초기값 설정: $EMA_0$는 일반적으로 첫 번째 관측치 $y_0$로 설정하거나, 단순 이동평균의 초기값으로 설정할 수 있다.
      - 지수 이동평균은 단순 이동평균에 비해 최근 데이터에 더 민감하게 반응하며, 금융 시장 분석 등에서 널리 활용된다.
      - 지수 이동평균은 과거 모든 관측치를 고려하지만, 지수적으로 감소하는 가중치를 부여하여 최근 데이터에 더 큰 영향을 미친다.
      - 따라서, 지수 이동평균은 단순 이동평균에 비해 최근 데이터의 변화에 더 민감하게 반응한다.
