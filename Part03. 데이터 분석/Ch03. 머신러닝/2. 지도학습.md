# 지도학습
## 1. 선형회귀
### 1. 단순 선형회귀와 다중 선형회귀
1. 단순 선형회귀
    - 하나의 설명 변수 x로 y를 설명하는 모형
    - 수식: $y = \beta_0 + \beta_1 x + \epsilon$
    - 2차원 공간의 직선 방정식의 형태로 x가 1 증가할 때마다 y사 이에 $\beta_1$만큼 증가
    - 오차항($\epsilon$)은 설명 변수로 설명하지 못하는 부분을 나타냄
2. 다중 선형회귀
    - 여러 개의 설명 변수로 관심변수 y를 설명하는 모형, p개의 설명 변수를 가질 수 있음
    - 수식: $y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_p x_p + \epsilon$
    - 다차원 공간에서 평면 또는 초평면의 형태로 각 설명 변수가 1 증가할 때마다 y가 해당 변수의 회귀계수만큼 증가
    - 오차항($\epsilon$)은 설명 변수로 설명하지 못하는 부분을 나타냄
### 2. 선형회귀의 주요 가정
1. 선형성
    - 설명 변수와 관심 변수 간의 관계가 선형이어야 함
    - 다중 선형회귀에서는 각 설명 변수와 관심 변수 간의 관계가 선형이어야 함
2. 독립성
    - 관측치들이 서로 독립적이어야 함
    - 시계열 데이터에서는 자기상관이 존재할 수 있으므로 주의 필요
3. 정규성
    - 오차항이 정규분포를 따라야 함
    - 잔차 분석을 통해 확인 가능
4. 등분산성
    - 오차항의 분산이 일정해야 함
    - 잔차 플롯을 통해 확인 가능
### 3. 비선형 관계를 반영한 회귀 모형
1. 다항 회귀
    - 설명 변수의 d차 다항식을 활용해 d차 곡선 및 곡면의 형태로 관심변수를 설명
    - 설명 변수의 다항식을 사용하여 비선형 관계를 모델링
    - 2개 이상의 설명 변수를 활용할 수 있으며, 두 설명 변수를 곱한 변수도 포함
    - 다중공선성 문제가 발생할 가능성이 높고, d가 커질수록 과적합 위험이 증가
    - 예: $y = \beta_0 + \beta_1 x + \beta_2 x^2 + ... + \beta_k x^k + \epsilon$
2. 비선형 회귀
    - 설명 변수의 선형 결합에 지수, 로그와 같은 비선형 변환 함수를 적용하여 관심 변수를 설명
    - 비선형 함수를 사용하여 설명 변수와 관심 변수 간의 관계를 모델링
    - 일반적으로 선형과 비선형의 구분은 모형식에서 각 설명 변수의 항이 "+"로 연결되어 분리가 가능한지를 기준으로 판단
    - 예: $y = \beta_0 + \beta_1 e^{\beta_2 x} + \epsilon$
### 4. 모형 적합 방법
1. 최적 회귀 방정식 계산
    - 실제 값과 모형식을 활용한 예측 값의 차이(오차)를 최소화하는 회귀 계수를 계산하고, 데이터에 적합한 최적 회귀 방정식을 계산
    - 최소제곱법은 오차의 제곱합을 최소화하는 방향으로 회귀계수를 계산하며, 이렇게 계산된 회귀계수를 최소제곱추정량이라 한다.
    - 예시) 단순 선형회귀의 오차 제곱합
      - $S(\beta_0, \beta_1) = \sum_{i=1}^{n} (y_i - (\beta_0 + \beta_1 x_i))^2$
2. 변수 선택 및 특성 선택
    - 계산된 회귀 계수($\beta_1$)가 0에 충분히 가까운 경우, $\beta_jX_j$도 0에 가까운 값으로 계산되며, $x_j$는 관심 변수 $y$에 거의 영향을 미치지 않음
    - 아래 가설로 회귀 계수 검정을 수행하여 유의하지 않은 설명 변수를 제거
      - 귀무가설($H_0$): $\beta_j = 0$ (설명 변수 $X_j$가 관심 변수 $y$에 영향을 미치지 않음) // 변수 $X_j$는 필요 없다.
      - 대립가설($H_a$): $\beta_j \neq 0$ (설명 변수 $X_j$가 관심 변수 $y$에 영향을 미침) // 변수 $X_j$는 필요 하다.
3. 변수 선택 방법
    - 회귀 모형에서 각 변수의 회귀 계수에 대한 검정과 모형의 성능 지표를 활용하여 모형에 필요한 변수를 순차적으로 선택 혹은 제거할 수 있고, 아래와 같은 방법을 활용한다.
      - 전진 선택법(Forward Selection): 빈 모형에서 시작하여 유의한 변수를 하나씩 추가
      - 후진 제거법(Backward Elimination): 전체 변수를 포함한 모형에서 시작하여 유의하지 않은 변수를 하나씩 제거
      - 단계적 선택법(Stepwise Selection): 전진 선택법과 후진 제거법을 결합하여 변수를 추가하거나 제거
4. 모형식을 활용한 예측
    - 최적 회귀 방정식을 활용하여 새로운 관측치에 대한 관심 변수 값을 예측
    - 예측 값 계산: $\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_p x_p$
    - 모형 평가 지표 등을 계산할 때, 실제 값($y_i$)과 예측 값($\hat{y_i}$)의 차이($y_i-\hat{y_i}$)를 활용하여 모델의 성능을 평가
5. 회귀 모형 평가
    - 수치형 관심변수를 활용하는 선형회귀는 모형평가, 변수 선택과정에서 RMSE, MAE, R² 등의 평가 지표를 활용
    - $R^2$은 변수의 유의성 여부와 상관없이 더 많은 변수를 활용한 모형이 더 높은 값을 갖고 좋은 모형으로 평가될 수 있으므로, 모형의 성능과 효율을 함께 고려해 변수의 개수를 고려한 평가지표를 활용
    - 예: 조정된 결정계수(Adjusted R²)
      - 공식: $Adjusted\ R^2 = 1 - (1 - R^2) \frac{n - 1}{n - p - 1}$
      - n: 관측치 수, p: 설명 변수 수
      - 해석: 값이 클수록 모델이 데이터를 잘 설명하며, 변수의 개수를 고려하여 평가
    - 예: AIC (Akaike Information Criterion)
      - 공식: $AIC = 2p - 2\log(\frac {\sum^n_{n=1}(y_i-\hat{y_i})} {n}) + 2k$
      - p: 설명 변수 수, L: 최대 우도 함수 값
      - 해석: 값이 작을수록 모델의 성능이 좋음
    - 예: BIC (Bayesian Information Criterion)
      - 공식: $BIC = p \log(\frac {\sum^n_{n=1}(y_i-\hat{y_i})} {n}) + klog(n)$
      - p: 설명 변수 수, n: 관측치 수, L: 최대 우도 함수 값
      - 해석: 값이 작을수록 모델의 성능이 좋음
    - 예: Mallow's $C_p$
      - 공식: $C_p = \frac{\sum_{i=1}^{n} (y_i - \hat{y_i})^2}{\hat{\sigma}^2} - n + 2(k+1)$
      - $\hat{\sigma}^2$: 전체 모형의 잔차 제곱평균, p: 설명 변수 수, n: 관측치 수
      - 해석: 값이 작을수록 모델의 성능이 좋음
### 5. 정규화 선형회귀

- 선형회귀 모형에 정규화(규제) 기법을 추가하여 과적합을 방지하고, 모델의 일반화 성능을 향상시키는 방법
1. 릿지 회귀(Ridge Regression)
    - 회귀 계수의 크기를 제한하여 과적합을 방지하는 정규화 기법
    - 비용 함수에 L2 정규화 항을 추가하여 회귀 계수를 제어
    - 비용 함수: $J(\beta) = \sum_{i=1}^{n} (y_i - \hat{y_i})^2 + \lambda \sum_{j=1}^{p} \beta_j^2$
    - $\lambda$는 정규화 강도를 조절하는 하이퍼파라미터로, 값이 클수록 회귀 계수가 더 작아짐
2. 라쏘 회귀
    - 회귀 계수의 절대값 합을 제한하여 과적합을 방지하는 정규화 기법
    - 비용 함수에 L1 정규화 항을 추가하여 회귀 계수를 제어
    - 비용 함수: $J(\beta) = \sum_{i=1}^{n} (y_i - \hat{y_i})^2 + \lambda \sum_{j=1}^{p} |\beta_j|$
    - $\lambda$는 정규화 강도를 조절하는 하이퍼파라미터로, 값이 클수록 일부 회귀 계수가 0이 되어 변수 선택 효과도 있음
3. 엘라스틱 넷 회귀(Elastic Net Regression)
    - 릿지 회귀와 라쏘 회귀의 장점을 결합한 정규화 기법
    - 비용 함수에 L1과 L2 정규화 항을 모두 추가하여 회귀 계수를 제어
    - 비용 함수: $J(\beta) = \sum_{i=1}^{n} (y_i - \hat{y_i})^2 + \lambda_1 \sum_{j=1}^{p} |\beta_j| + \lambda_2 \sum_{j=1}^{p} \beta_j^2$
    - $\lambda_1$과 $\lambda_2$는 각각 L1과 L2 정규화 강도를 조절하는 하이퍼파라미터

## 2. 로지스틱 회귀
### 1. 로지스틱 회귀 개요
- 이진 분류 문제를 해결하기 위한 지도학습 알고리즘
- 관심 변수 y가 특정 범주에 속할 확률을 계산하고 예측에 활용
- 시그모이드 함수 혹은 로지스틱 함수를 활용하여 확률 값을 0과 1 사이로 변환
  - 시그모이드 함수: $S(z) = \frac{1}{1 + e^{-z}}$
  - 로지스틱 회귀 모형식: $P(y=1|X) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_p x_p)}}$
### 2. 로지스틱 회귀 개념 이해
1. 오즈(Odds)
    - 오즈: 사건이 발생할 확률과 발생하지 않을 확률의 비율
      - 공식: $Odds = \frac{P(y=1|X)}{1 - P(y=1|X)}$
2. 로그 오즈(Log-Odds)
    - 로그 오즈: 오즈의 자연로그 변환
      - 공식: $Log-Odds = \log\left(\frac{P(y=1|X)}{1 - P(y=1|X)}\right)$
### 3. 모형 적합 방법
1. Log loss의 정의
    - 로지스틱 회귀에서 모형 적합을 위해 사용되는 손실 함수
    - 관측치의 실제 값과 예측 확률 간의 차이를 측정
    - 공식: $Log\ Loss = -\frac{1}{n} \sum_{i=1}^{n} \left[ y_i \log(\hat{y_i}) + (1 - y_i) \log(1 - \hat{y_i}) \right]$
2. 회귀 계수 추정
    - 선형회귀 모형과 마찬가지로 모든 관측치 $l_i$의 합 $l$을 최소화하는 회귀 계수 $\beta_i$를 추정
    - 실제 회귀 계수의 계산 과정에서는 경사하강법을 활용해 점진적으로 더 나은 값을 찾아가는 수치해석 등의 방법을 활용한다.
## 3. 나이브 베이즈 분류
### 1. 개념
- 베이즈 정리를 기반으로 한 확률적 분류 알고리즘
- 각 특징이 독립적이라는 가정 하에 클래스에 속할 확률을 계산
- 베이즈 정리: $P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$
- 나이브 베이즈 분류 모형식: $P(C_k|X) = \frac{P(X|C_k) \cdot P(C_k)}{P(X)}$
### 2. 확률 계산 및 분류
- 관심변수 y가 k개의 클래스 $C_1, C_2, ..., C_k$를 가질 때, 새로운 관측치 X에 대해 각 클래스에 속할 확률을 계산
- 별도의 추정 과정 없이 학습 데이터에서 각 클래스의 사전 확률 $P(C_k)$와 특징의 조건부 확률 $P(X|C_k)$를 계산하여 사용
- 새로운 관측치 X에 대해 각 클래스에 속할 확률을 계산하고, 가장 높은 확률을 갖는 클래스로 분류
- 분류 결정: $\hat{C} = \arg\max_{C_k} P(C_k|X)$
## 4. 서포트 백터 머신
- 회귀와 분류에 모두 활용 가능하나, 일반적으로 이진 분류에 활용하여 관심 변수 y가 두 개의 클래스(예: 1과 -1)로 구분되는 문제를 해결
- 범주 또는 클래스가 가장 큰 마진을 두고 나뉠 수 있도록 결정 경계(Decision Boundary)를 찾는 것을 목표
- 결정 경계는 서포트 벡터(Support Vectors)라 불리는 가장 가까운 데이터 포인트에 의해 결정
- 선형 SVM과 비선형 SVM으로 구분
1. 선형 SVM
    - 데이터가 선형적으로 구분 가능한 경우, 최적의 결정 경계를 찾기 위해 선형 초평면을 사용
    - 결정 경계 수식: $w \cdot x + b = 0$
    - 마진 최대화: $\text{maximize} \frac{2}{||w||}$
2. 비선형 SVM
    - 데이터가 선형적으로 구분되지 않는 경우, 커널 트릭(Kernel Trick)을 활용하여 고차원 공간으로 매핑
    - 커널 함수 예시:
      - 다항 커널: $K(x_i, x_j) = (x_i \cdot x_j + c)^d$
      - RBF 커널: $K(x_i, x_j) = \exp(-\gamma ||x_i - x_j||^2)$
- SVM은 강력한 분류 성능과 일반화 능력을 갖추고 있어 다양한 분야에서 널리 사용
