# 추정과 통계 검정
## 1. 추정
### 1. 통계량을 활용한 모수 추정
- 모집단의 특성을 나타내는 모수(Parameter)는 일반적으로 알려져 있지 않으므로, 표본에서 계산된 통계량(Statistic)을 활용하여 모수를 추정
- 추정: 모집단에서 표본을 추출하고, 표본에서 계산된 통계량을 이용하여 모집단의 모수를 유추하는 과정

1. 점 추정(Point Estimation)
    - 모수의 정확한 값을 하나의 통계량으로 추정하는 방법
    - 단점: 추정값이 하나이므로, 추정의 불확실성을 반영하지 못함
      - 예: 표본 평균 $\bar{x}$를 이용하여 모집단 평균 $\mu$를 추정
      - 예: 표본 분산 $s^2$을 $n-1$로 나누어, 모집단 분산 $\sigma^2$를 추정

2. 구간 추정(Interval Estimation)
    - 모수가 포함될 것으로 예상되는 값의 범위를 추정하는 방법으로, 확률분포를 활용, 추정된 구간을 신뢰구간으로 부름
    - 신뢰구간(Confidence Interval): 모수가 특정 구간 내에 포함될 확률을 나타내는 구간
      - 신뢰 수준은 $(1-\alpha) \times 100\%$로 표현하며, $\alpha$는 유의수준(Significance Level)
      - 신뢰 수준을 높이면 모수가 해당 구간에 포함될 확률은 높아지지만, 신뢰 구간의 범위도 넓어짐
      - 신뢰 수준을 낮추면 모수가 해당 구간에 포함될 확률은 낮아지지만, 신뢰 구간의 범위는 좁아짐
    
### 2. 표준오차
- 표본에서 계산된 통계량이 모집단의 모수를 얼마나 잘 추정하는지를 나타내는 지표
- 추정 및 검정에서 사용되며, 통계량의 표준편차를 활용
- 모집단과 표본의 관점에서 데이터는 특정한 확률분포를 따른다고 가정, 관측치를 집계하여 계산한 통계량도 확률분포를 따르므로 표준편차를 계산할 수 있음

## 2. 통계적 가설 검정
### 1. 통계적 가설 검정의 개념
- 모집단의 특성에 대한 주장이나 가설에 대해 표본에서 확인한 정보를 기준으로 판단하는 과정
- 통계 검정은 서로 반대되는 귀무가설과 대립가설 중 하나를 선택하는 확률적인 판단 절차

1. 귀무가설(Null Hypothesis, $H_0$)
    - 검정하고자 하는 가설로, 일반적으로 '차이가 없다', '효과가 없다'는 내용을 포함
    - 예: 두 집단의 평균이 같다, 두 변수 간에 상관관계가 없다
2. 대립가설(Alternative Hypothesis, $H_1$)
    - 귀무가설과 반대되는 가설로, '차이가 있다', '효과가 있다'는 내용을 포함
    - 예: 두 집단의 평균이 다르다, 두 변수 간에 상관관계가 있다
3. 유의확률, p-값(p-value)
    - 귀무가설이 참일 때, 관측된 데이터보다 극단적인 결과가 나타날 확률
    - p-값이 작을수록 귀무가설을 기각할 근거가 강해짐
      - 일반적으로 유의수준 $\alpha$ (예: 0.05)와 비교하여, p-값이 $\alpha$보다 작으면 귀무가설을 기각
      - p-값이 1에 가까울수록 귀무가설이 맞다는 가정하에서도 실제 데이터의 통계량이나 정보가 충분히 발생할 수 있다는 의미
      - p-값이 0에 가까울수록 귀무가설이 맞다는 가정하에서는 실제 데이터의 통계량이나 정보가 발생할 가능성이 매우 낮다는 의미
        - 귀무가설이 참이라는 가정 자체가 잘못된 것을 의미, 따라서 귀무가설을 기각하고 대립가설을 채택
4. 검정통계량(Test Statistic)
    - 검정을 계산하기 위해 데이터에서 계산하는 통계량, 각 검정 통계량에 대응하는 확률분포를 함꼐 활용
    - 계산된 검정 통계량과 더 나아가 p-값을 활용하여 귀무가설을 기각할지 여부를 결정
    - 연구와 논문으로 증명된 사실을 바탕으로 특정한 상황에서 어떤 검정 통계량을 계산하고 어떤 확률분포를 활용해야 할 지 결정
      - 특정한 상황에 적합한 검정 통계량과 확률분포는 결정되어 있음
5. 유의수준(Significance Level, $\alpha$)
    - 귀무가설이 참일 때, 귀무가설을 잘못 기각할 확률
    - 계산된 유의확률이 1에 가까울수록 귀무가설을 기각할 가능성이 낮아지고, 0에 가까울수록 귀무가설을 기각할 가능성이 높아짐
    - 일반적으로 0.05(5%)나 0.01(1%)로 설정 -> 수학적으로 증명된 것이 아닌, 합의에 의한 것
6. 1종 오류(Type 1 Error)와 2종 오류(Type 2 Error)
    - 1종 오류: 귀무가설이 참인데도 불구하고 귀무가설을 기각하는 오류
      - 유의수준 $\alpha$로 정의되며, 일반적으로 5%나 1%로 설정
      - 유의수준이 고정된 1종 오류 허용 수준을 의미
    - 2종 오류: 귀무가설이 거짓인데도 불구하고 귀무가설을 채택하는 오류
      - 2종 오류의 확률은 $\beta$로 표현되며, 검정력(Power)은 $1-\beta$로 정의
      - 검정력은 실제로 대립가설이 참일 때, 귀무가설을 올바르게 기각할 확률
### 2. t-분포를 활용한 검정 // 연속형 변수에 사용
1. 일표본 t-검정(One-sample t-test)
    - 모집단의 평균이 특정한 값과 다른지 여부를 검정
    - 가설 설정
      - 귀무가설: X의 평균은 $\mu_0$와 같다.
      - 대립가설: X의 평균은 $\mu_0$와 다르다.
    - 검정통계량: $ t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}} $
      - $\bar{x}$: 표본 평균, $\mu_0$: 가설에서 제시한 모집단 평균, $s$: 표본 표준편차, $n$: 표본 크기
2. 독립표본 t-검정(Independent two-sample t-test)
    - 두 독립된 집단의 평균이 서로 다른지 여부를 검정
    - 가설 설정
      - 귀무가설: X와 Y의 평균은 같다.
      - 대립가설: X와 Y의 평균은 다르다.
    - 검정통계량: $ t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}} $
      - $\bar{x}_1, \bar{x}_2$: 각 집단의 표본 평균, $s_1, s_2$: 각 집단의 표본 표준편차, $n_1, n_2$: 각 집단의 표본 크기
3. 대응표본 t-검정(Paired sample t-test)
    - 동일한 대상에서 두 번의 측정을 수행한 경우, 두 측정값의 평균 차이가 유의미한지 검정
    - 가설 설정
      - 귀무가설: 두 측정값의 평균 차이는 0이다.
      - 대립가설: 두 측정값의 평균 차이는 0이 아니다.
    - 검정통계량: $ t = \frac{\bar{d}}{s_d / \sqrt{n}} $
      - $\bar{d}$: 각 쌍의 차이의 평균, $s_d$: 차이의 표본 표준편차, $n$: 쌍의 개수
4. 상관분석
    - 두 변수 간의 선형 상관관계가 유의미한지 검정
    - 가설 설정
      - 귀무가설: 두 변수 간에 상관관계가 없다. ($\rho = 0$)
      - 대립가설: 두 변수 간에 상관관계가 있다. ($\rho \neq 0$)
    - 검정통계량: $ t = \frac{r \sqrt{n-2}}{\sqrt{1-r^2}} $
      - $r$: 피어슨 상관계수, $n$: 관측치의 개수
### 3. 카이제곱 분포를 활용한 검정 // 범주형 변수에 사용
1. 적합도 검정(Goodness-of-fit test)
    - 관측된 빈도 분포가 기대되는 이론적 분포와 일치하는지 검정
    - 가설 설정
      - 귀무가설: 관측된 빈도 분포는 기대되는 분포와 일치한다.
      - 대립가설: 관측된 빈도 분포는 기대되는 분포와 일치하지 않는다.
    - 검정통계량: $ \chi^2 = \sum \frac{(O_i - E_i)^2}{E_i} $
      - $O_i$: 관측된 빈도, $E_i$: 기대되는 빈도
2. 독립성 검정(Test of independence)
    - 두 범주형 변수 간에 독립성이 있는지 검정
    - 가설 설정
      - 귀무가설: 두 변수는 독립적이다.
      - 대립가설: 두 변수는 독립적이지 않다.
    - 검정통계량: $ \chi^2 = \sum \frac{(O_{ij} - E_{ij})^2}{E_{ij}} $
      - $O_{ij}$: 관측된 빈도, $E_{ij}$: 기대되는 빈도
3. 동질성 검정(Test of homogeneity)
    - 여러 집단 간에 특정 범주형 변수의 분포가 동일한지 검정
    - 가설 설정
      - 귀무가설: 모든 집단의 분포는 동일하다.
      - 대립가설: 적어도 하나의 집단의 분포는 다르다.
    - 검정통계량: $ \chi^2 = \sum \frac{(O_{ij} - E_{ij})^2}{E_{ij}} $
      - $O_{ij}$: 관측된 빈도, $E_{ij}$: 기대되는 빈도
### 4. F-분포를 활용한 검정 // 분산분석에 사용
1. 일원분산분석(One-way ANOVA)
    - 세 개 이상의 독립된 집단 간에 평균 차이가 있는지 검정
    - 가설 설정
      - 귀무가설: 모든 집단의 평균은 같다.
      - 대립가설: 적어도 하나의 집단의 평균은 다르다.
    - 검정통계량: $ F = \frac{\text{집단 간 변동}}{\text{집단 내 변동}} $
    - 표기법 정의 및 제곱합 계산
      - TSS: $ \text{총 제곱합} = \sum \sum (x_{ij} - \bar{x})^2 $
      - SST: $ \text{처리 간 제곱합} = \sum \sum (\bar{x}_j - \bar{x})^2 $
      - SSE: $ \text{오차 제곱합} = \sum \sum (x_{ij} - \bar{x}_j)^2 $
      - TSS = SST + SSE
2. 이원분산분석(Two-way ANOVA)
    - 두 개의 독립변수가 종속변수에 미치는 영향을 동시에 검정
    - 가설 설정
      - 귀무가설: 각 독립변수의 주효과와 상호작효과는 없다.
      - 대립가설: 적어도 하나의 주효과나 상호작효과는 있다.
    - 검정통계량: $ F = \frac{\text{처리 변동}}{\text{오차 변동}} $

### 5. 비모수적 검정 // 데이터가 정규분포를 따르지 않거나, 표본 크기가 작을 때 사용
- 모수적 검정은 검정 과정에서 데이터의 정규성을 가정하며, 충분한 관측치 수를 필요로 하거나 등분산성, 독립성 등을 추가로 가정하고 이 가정을 충족하지 못할 경우 해당 검정을 활용하지 못하거나 검정 결과의 신뢰성이 저하될 수 있다.
- 비모수적 검정은 이러한 가정에 덜 민감하며, 데이터의 분포에 대한 가정이 적거나 없기 때문에 다양한 상황에서 활용 가능
  - 비모수적 검정은 데이터의 순위나 빈도와 같은 비모수적 특성을 활용하여 검정을 수행
  - 비모수적 검정은 일반적으로 모수적 검정보다 검정력이 낮을 수 있지만, 데이터의 특성에 맞게 적절히 활용하면 유용한 결과를 얻을 수 있음
  - 비모수적 검정은 특히 데이터가 정규분포를 따르지 않거나, 표본 크기가 작을 때 유용
  - 비모수적 검정은 귀무가설 혹은 대립가설과 완벽하게 대응되지 않을 수 있음

1. 윌콕슨 부호순위 검정(Wilcoxon Signed-Rank Test)
    - 대응표본 t-검정의 비모수적 대안으로, 두 관련된 집단 간의 차이를 검정
    - 가설 설정
      - 귀무가설: 두 관련된 집단의 중앙값 차이는 0이다.
      - 대립가설: 두 관련된 집단의 중앙값 차이는 0이 아니다.
2. 맨-휘트니 U 검정(Mann-Whitney U Test) 혹은 윌콕슨 순위합 검정
    - 독립표본 t-검정의 비모수적 대안으로, 두 독립된 집단 간의 차이를 검정
    - 가설 설정
      - 귀무가설: 두 독립된 집단의 분포는 같다.
      - 대립가설: 두 독립된 집단의 분포는 다르다.
      - 두 집단의 중앙값이 다르다는 가설과 완벽하게 대응되지 않을 수 있음
    - 수식
      - $ U = n_1 n_2 + \frac{n_1 (n_1 + 1)}{2} - R_1 $
        - $ n_1, n_2 $: 각 집단의 표본 크기
        - $ R_1 $: 집단 1의 관측치 순위 합
3. 크루스칼-왈리스 검정(Kruskal-Wallis Test)
    - 일원분산분석의 비모수적 대안으로, 세 개 이상의 독립된 집단 간의 차이를 검정
    - 가설 설정
      - 귀무가설: 모든 독립된 집단의 분포는 같다.
      - 대립가설: 적어도 하나의 독립된 집단의 분포는 다르다.
      - 세 개 이상의 집단의 중앙값이 다르다는 가설과 완벽하게 대응되지 않을 수 있음
    - 수식
      - $ H = \frac{12}{N(N+1)} \sum \frac{R_j^2}{n_j} - 3(N+1) $
        - $ N $: 전체 관측치 수
        - $ R_j $: 집단 $j$의 관측치 순위 합
        - $ n_j $: 집단 $j$의 표본 크기
4. 프리드만 검정
   - 이원분산분석의 비모수적 대안으로, 세 개 이상의 관련된 집단 간의 차이를 검정
   - 가설 설정
     - 귀무가설: 모든 관련된 집단의 분포는 같다.
     - 대립가설: 적어도 하나의 관련된 집단의 분포는 다르다.
     - 세 개 이상의 관련된 집단의 중앙값이 다르다는 가설과 완벽하게 대응되지 않을 수 있음
   - 수식
     - $ Q = \frac{12}{n k (k+1)} \sum R_j^2 - 3n(k+1) $
       - $ n $: 각 블록의 수
       - $ k $: 처리의 수
       - $ R_j $: 처리 $j$의 순위 합
5. Fisher의 정확 검정(Fisher's Exact Test)
    - 두 범주형 변수 간의 독립성을 검정하는 비모수적 방법
    - 가설 설정
      - 귀무가설: 두 범주형 변수는 독립적이다.
      - 대립가설: 두 범주형 변수는 독립적이지 않다.
    - 수식
      - $ P = \frac{(a+b)!(c+d)!(a+c)!(b+d)!}{a!b!c!d!n!} $
        - $ a, b, c, d $: 2x2 교차표의 셀 빈도
        - $ n $: 전체 관측치 수
