# 통계분석의 이해
## 1. 확률과 확률분포
### 1. 확률과 조건부 확률
1. 확률
    - 어떤 사건이 발생할 가능성을 0에서 1 사이의 값으로 나타낸 것
    - $ P(A) = \frac{\text{사건 A가 발생하는 경우의 수}}{\text{전체 경우의 수}} = \frac{n(A)}{n(\Omega)} $
    - 두 사건이 동시에 발생할 사건은 $ P(A \cap B) $ 표현하고, 이에 대한 확률은 $ P(A \cap B) = P(A) \times P(B|A) $ 로 계산
    - 두 사건 중 하나라도 발생할 사건은 $ P(A \cup B) $ 로 표현하고, 이에 대한 확률은 $ P(A \cup B) = P(A) + P(B) - P(A \cap B) $ 로 계산
2. 조건부 확률
    - 어떤 사건(A)이 발생했을 때, 다른 사건(B)이 발생할 확률
    - $ P(B|A) = \frac{P(A \cap B)}{P(A)} $
    - 베이즈 정리: $ P(A|B) = \frac{P(B|A) \times P(A)}{P(B)} $
### 2. 독립사건과 배반사건
1. 독립사건
    - 두 사건 A와 B가 서로 영향을 미치지 않는 경우
    - $ P(B|A) = \frac{n(A \cap B)}{n(A)} = P(B) $
    - $ P(A \cap B) = P(A) \times P(B) $
2. 배반사건
    - 두 사건 A와 B가 동시에 발생할 수 없는 경우
    - 한 사건이 발생하면 다른 사건이 절대 발생할 수 없으므로 서로의 발생 확률에 영향을 미치며, 조건부 확률은 0이며 독립이 아니다.
    - $ P(A \cap B) = 0 $
    - $ P(A \cup B) = P(A) + P(B) $
### 3. 확률변수와 확률분포
1. 확률분포
    - 고정되지 않은 임의의 실수 값을 갖는 확률변수가 특정 값을 가질 확률을 나타내는 함수
2. 이산형 확률분포
    - 확률변수가 유한하거나 셀 수 있는 값을 가질 때의 확률분포
    - 이산형 확률변수 $X$
3. 연속형 확률분포
    - 확률변수가 연속적인 값을 가질 때의 확률분포
4. 결합 확률분포
    - 두 확률 변수 $X$와 $Y$가 각각 특정한 값을 갖는 확률을 계산한 것
    - 두 확률 변수가 독립이라고 가정하면, 각각의 확률분포에서 계산된 확률의 곱으로 확률을 계산

### 4. 경험적 분포와 이론적 분포
1. 경험적 분포
    - 전체 관측치에서 관심있는 조건 및 영역에 해당하는 관측치의 비율을 계산
2. 이론적 분포
    - 어떤 확률변수를 정의할 때 설정된 가상 또는 이론적인 분포
    - 이론적인 지식과 경험을 바탕으로 직접 확률분포를 정의할 수 있고, 미리 설계된 기성 분포를 가정하고 활용할 수 있다.
    - 기성 분포는 특정한 상황에서 활용할 수 있도록 확률 질량 함수 및 확률 밀도 함수가 정의되어 있으며, 각 함수마다 모수가 설정되어 모수가 달라지면 함수 값과 확률이 바뀐다.
3. 경험적 확률과 이론적 확률
    - 경험적 확률: 실제 관측된 데이터를 바탕으로 계산된 확률
    - 이론적 확률: 이론적 분포에 따라 계산된 확률, 실제로는 데이터를 이용해 분포의 모수를 추정하여 활용

### 5. 주요 이산형 확률분포
1. 베르누이 분포
    - 두 가지 결과(성공/실패) 중 하나를 갖는 확률변수의 분포
    - $ P(X=1) = p, \; P(X=0) = 1-p $
2. 이항 분포
    - 독립적인 베르누이 시행을 $n$번 반복했을 때, 성공 횟수의 분포
    - $ P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}, \ k=0,1,2...n $
3. 포아송 분포
    - 단위 시간 또는 공간 내에서 특정 사건이 발생하는 횟수의 분포
    - $ P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}, \ k=0,1,2... $

### 6. 대표적인 연속형 확률분포
1. 균일 분포
   - 모든 값이 동일한 확률을 가지는 분포
   - $ f(x) = \frac{1}{b-a}, \ a \leq x \leq b $
2. 정규 분포
   - 정규 분포의 확률 밀도 함수 $f(x)$는 위치 모수 $\mu$와 척도 모수 $\sigma$에 의해 결정
   - $ f(x) = \frac{1}{\sigma \sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}} $
3. 표준 정규 분포
   - 위치 모수가 0이고 척도 모수$\sigma$가 1인 정규 분포
   - $ Z = \frac{X - \mu}{\sigma} $
4. 지수 분포
   - 특정한 사건이 반복될 때 사건이 발생하는 시간 간격을 나타내는 분포
   - $ f(x) = \lambda e^{-\lambda x}, \ x \geq 0 $
5. t-분포
    - 모집단의 분산이 알려지지 않은 경우, 표본 평균의 분포를 나타내는 분포
    - 자유도 $df = n - 1$ 인 t-분포의 확률 밀도 함수
    - $ f(t) = \frac{\Gamma(\frac{df+1}{2})}{\sqrt{df\pi} \Gamma(\frac{df}{2})} \left(1 + \frac{t^2}{df}\right)^{-\frac{df+1}{2}} $

### 7. 기댓값과 분산, 표준편차
1. 기댓값(Expected Value)
    - 확률변수가 가질 수 있는 값에 확률을 곱하여 모두 더한 값
    - 이산형 확률변수: $ E(X) = \sum_{i} x_i P(X=x_i) $
    - 연속형 확률변수: $ E(X) = \int_{-\infty}^{\infty} x f(x) dx $
2. 분산(Variance)
    - 확률변수가 기댓값으로부터 얼마나 떨어져 있는지를 나타내는 척도
    - 이산형 확률변수: $ Var(X) = E[(X - E(X))^2] = \sum_{i} (x_i - E(X))^2 P(X=x_i) $
    - 연속형 확률변수: $ Var(X) = E[(X - E(X))^2] = \int_{-\infty}^{\infty} (x - E(X))^2 f(x) dx $
3. 표준편차(Standard Deviation)
    - 분산의 제곱근으로, 확률변수가 기댓값으로부터 얼마나 떨어져 있는지를 나타내는 척도
    - $ SD(X) = \sqrt{Var(X)} = \sqrt{\sigma^2_x}$
4. 왜도(Skewness)와 첨도(Kurtosis)
    - 왜도: 확률분포의 비대칭성을 나타내는 척도
      - 수식: $ \text{Skewness} = \frac{E[(X - \mu)^3]}{\sigma^3} $
    - 첨도: 확률분포의 뾰족한 정도를 나타내는 척도
      - 수식: $ \text{Kurtosis} = \frac{E[(X - \mu)^4]}{\sigma^4} - 3 $
5. 분위수
   - 특정 확률에 해당하는 값을 나타내는 척도
   - $ p $ 분위수: $ P(X \leq x_p) = p $
6. 공분산
   - 두 확률변수 간의 관계를 나타내는 척도
   - $ \text{Cov}(X, Y) = E[(X - E(X))(Y - E(Y))] $
7. 상관계수
   - 두 확률변수 간의 선형 관계를 나타내는 척도
   - $ \text{Corr}(X, Y) = \frac{\text{Cov}(X, Y)}{SD(X) \times SD(Y)} $
